Changelog

3.7 - 31.10.2026

  • The results page now shows your three closest ideologies instead of one. Opening any ideology (from the results or the ideology list) shows its name, its values laid out by category and its description. Use the arrows to browse its other value sets. When opened from your results, each value is ringed by how it compares with yours: green for the same or a close value, yellow to red for clashes (from mild to extreme) and gray for unrelated.
  • Reworked how the closest ideologies are chosen: a clashing value now lowers the score by an amount that depends on how serious the clash is, instead of removing the ideology completely.
  • Rarer values now count for more, ideologies with several value sets no longer get an unfair advantage, and ties go to the ideology you match more closely.
  • Added 23 new pairs of clashing sub-groups, and some values (for example Neocorporatism) now belong to more than one sub-group.
  • The closest ideologies are shown as outlined bubbles in the ideology's color, like the original "Next closest match". Long names now wrap the same way as in the original, both there and in the value names on the ideology page.

3.6 - 30.10.2026

  • The project is now called HyperValues (previously NeoValues).
  • Changed how the "Next closest match" is chosen: it now also considers how many of an ideology's own values you match, so ideologies that only share a few loosely related values with you no longer beat ideologies that fit you better.
  • Removed the Contact, Support and Other tests pages and links.
  • The GitHub icon now links to the HyperValues repository.
